# Top App Picks

Research of US App Store apps in the self-improvement niche: apps built by small developers that reached real traction with little marketing, are easy to build and easy to market.

- Dashboard: `research/output/dashboard.html` (open directly in a browser, or serve `research/output` locally)
- Top 100 list: `research/output/top-picks_*.csv`
- Method, scripts and folder layout: `research/README.md`
- Methodology and profile template (Claude skill): `.claude/skills/viral-app-research/SKILL.md`

Data sources: Apple App Store (US) public endpoints, Meta Ad Library, App Store reviews, Reddit via Google search. Download and revenue figures are not public for iOS; ratings and reviews are used as relative signals.
